# 한평생 에듀바이저스  (프로젝트 개요)

## Overview

`에듀바이저스`는 한국평생교육그룹의 웹 포트폴리오 및 서비스 사이트로, Next.js(앱 라우터)를 기반으로 하는 기업 사이트 및 관리(Admin) 도구를 포함합니다. 프로젝트는 마케팅용 메인 사이트(홈, 소개, 서비스, 채용 등)와 내부 운영을 위한 관리 인터페이스(팝업 관리, 상담 관리, 채용 지원 관리 등)를 함께 포함하여 운영성과 관리 편의성을 고려한 구조로 설계되어 있습니다.

주요 구조 요약:
- `app/` — Next.js App Router 기반의 페이지 및 레이아웃, 서버/클라이언트 경계가 명확히 분리되어 있음.
- `components/` — 재사용 가능한 UI 컴포넌트 집합(헤더, 푸터, 팝업, 모달, 테이블 등).
- `public/images` — 사이트에서 사용하는 정적 이미지 자원.
- `lib/` — 외부 서비스 연동 코드(`supabase.ts`, `slack.ts`, `admin-auth.ts` 등).

이 프로젝트는 사용자용 퍼블릭 페이지와 관리용 대시보드를 하나의 코드베이스에서 운영하면서도 다음과 같은 목표를 달성하고자 했습니다: 빠른 페이지 로드, 접근성 및 반응형 UX 보장, 관리자가 쉽게 컨텐츠(팝업, 공고, 상담 등)를 운영할 수 있도록 하는 것.

## 사용 기술

- 프레임워크: Next.js (App Router)
- 언어: TypeScript, React
- 스타일링: Tailwind CSS, CSS Modules, PostCSS
- 인증 / DB: Supabase (인증, 스토리지, 데이터베이스 연동)
- 알림/연동: Slack 연동(`lib/slack.ts`)으로 운영 알림 전송
- 빌드/도구: Vite(개별 컴포넌트 상황에 따라), ESLint, Prettier 설정(프로젝트 구성에 따라)
- 배포: Vercel 또는 정적 호스팅 권장(Next.js 최적화 적용)
- 기타: 이미지 최적화(Next.js 이미지 사용 권장), 서버 미들웨어(`middleware.ts`)를 통한 라우팅/인증 처리

## 도전과제 및 해결책

1) 팝업(모달) 상태를 앱 전역에서 안정적으로 관리해야 함
	- 해결책: `PopupManager` 컴포넌트와 `ModalProvider`를 도입해 클라이언트 전역 상태로 팝업을 중앙에서 제어하도록 설계. `POPUP_USAGE.md`에 사용법 문서화.

2) 관리자 전용 기능(로그인, 권한, 팝업/상담 관리)의 보안 및 UX 확보
	- 해결책: 서버사이드 미들웨어 및 `lib/admin-auth.ts`를 사용해 인증 경로를 보호. UI는 데이터 테이블 및 필터 컴포넌트를 통해 직관적으로 구성.

3) 이미지 자산이 많아 페이지 성능에 영향
	- 해결책: 필요한 곳에서 lazy-loading과 크기별 소스 제공, Next.js의 이미지 최적화 기능을 활용.

4) 컨텐츠(팝업, 공지, 채용 등) 운영 편의성
	- 해결책: 관리 화면에서 콘텐츠 CRUD를 쉽게 할 수 있도록 폼과 테이블을 구성하고, 변경 시 Slack 알림을 통해 운영자에게 통지되도록 자동화.

5) 서버-클라이언트 경계에서의 데이터 처리 및 렌더링 전략
	- 해결책: Next.js의 서버 컴포넌트와 클라이언트 컴포넌트를 적절히 분리하여 서버에서 가능한 데이터 페칭을 수행하고, 클라이언트 쪽은 상호작용 관련 코드만 포함.

## 결과 및 성과

- 재사용 가능한 컴포넌트 라이브러리 구축으로 개발 생산성 향상(헤더/푸터, 팝업, 모달, 테이블 등).
- 관리자 페이지를 통해 비기술 운영자가 팝업과 상담, 공고 등을 직접 관리할 수 있게 되어 운영 비용 감소.
- 이미지 및 리소스 가이드 적용으로 페이지 로딩 성능 개선과 모바일 반응성 향상.
- Slack 연동으로 운영 이슈 알림 자동화, 빠른 대응 가능.
- Next.js 기반으로 SEO(사이트맵, robots.txt 포함) 및 배포 최적화가 이루어짐.
